## Topics Covered

- **Hardware basics:** CPU, chipset, motherboard, sockets, power supply
- **x86 assembly (MASM):** registers (`EAX`, `AX`, `ESI`, `EDI`), `mov`, `add`, `sub`, data directives
- **Memory and arrays:** `OFFSET`, indexed addressing, loops
- **Control flow:** binary and logical instructions, conditional jumps, IF structures
- **Procedures:** `PROC`, `invoke`, stack operations
- **C with inline assembly:** dot product, Hamming weight
- **Advanced:** floating-point operations, loop unrolling, MMX
